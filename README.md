# Nouhaila Hassi · Portfolio

Static portfolio site (plain HTML, no build step).

- `index.html` – homepage
- `cases.html` – all case studies
- `case-pms.html`, `case-ai.html`, `case-roadmap.html` – single case pages
- `Nouhaila_Hassi_CV.pdf` – downloadable CV

Hosted with GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
